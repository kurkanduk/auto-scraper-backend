# 🤖 Car Scraper Bot

Автоматический бот для поиска и отправки сообщений о продаже автомобилей частными лицами на популярных площадках: mobile.de, otomoto, и bazos.

## 🎯 Функционал

- **Автоматический скрэпинг** каждые 5-30 минут с сайтов:
  - 🇩🇪 mobile.de (Германия)
  - 🇵🇱 otomoto (Польша)
  - 🇨🇿 bazos (Чехия)
- **Фильтрация объявлений** по параметрам (цена, год, пробег, тип продавца)
- **Автоматическая отправка WhatsApp сообщений** частным продавцам
- **База данных** для отслеживания обработанных объявлений
- **REST API** для мониторинга и управления
- **Защита от дублирования** сообщений

## 🚀 Быстрый старт

### 1. Установка

```bash
# Клонируйте репозиторий
git clone <repo-url>
cd project-name

# Запустите установку
./setup.sh
```

### 2. Настройка фильтров

Отредактируйте файл `src/config/app.config.ts`:

```typescript
filtering: {
  maxPrice: 50000,        // Максимальная цена
  minYear: 2015,          // Минимальный год выпуска
  maxMileage: 150000,     // Максимальный пробег
  allowedFuelTypes: ['petrol', 'diesel', 'hybrid', 'electric'],
  excludeKeywords: ['accident', 'damage', 'salvage', 'export'],
  requiredKeywords: [],   // Обязательные ключевые слова
}
```

### 3. Настройка сообщения WhatsApp

```typescript
whatsapp: {
  messageTemplate: `Здравствуйте! Меня интересует ваше объявление о продаже автомобиля {make} {model} {year} года...`,
  maxMessagesPerHour: 10,
}
```

### 4. Запуск

```bash
# Режим разработки
yarn start:dev

# Продакшн
yarn start:prod
```

## 📱 Настройка WhatsApp

При первом запуске вам необходимо:

1. Отсканировать QR-код в терминале с помощью WhatsApp
2. Бот автоматически авторизуется и начнет работу
3. Данные авторизации сохраняются локально

## 🔧 API Endpoints

### Статус бота

```http
GET /scraping/status
```

### Запуск ручного скрэпинга

```http
POST /scraping/start?source=mobile.de
```

### Последние объявления

```http
GET /scraping/listings?limit=10
```

### Логи отправленных сообщений

```http
GET /scraping/contacts?limit=10
```

### Тестирование фильтров

```http
GET /scraping/test-filter?title=BMW%203er&price=25000&year=2018
```

## 📊 Мониторинг

Откройте `http://localhost:3000/scraping/status` для просмотра:

- Статистики скрэпинга
- Состояния WhatsApp клиента
- Статистики отправленных сообщений
- Настроек фильтрации

## 🗄️ База данных

Используется SQLite с таблицами:

- `listings` - все найденные объявления
- `contact_logs` - история отправленных сообщений

## ⚙️ Конфигурация

### Интервал скрэпинга

Измените в `src/modules/scraping/services/scraping.service.ts`:

```typescript
// Каждые 15 минут
@Cron('0 */15 * * * *')

// Каждые 30 минут
@Cron('0 */30 * * * *')

// Каждые 5 минут
@Cron('0 */5 * * * *')
```

### Фильтры по сайтам

Каждый скрэпер можно настроить индивидуально в соответствующих файлах:

- `mobile-de-scraper.service.ts`
- `otomoto-scraper.service.ts`
- `bazos-scraper.service.ts`

## 🛡️ Безопасность

- Используйте headless браузер для скрэпинга
- Ограничения на количество сообщений в час
- Случайные задержки между запросами
- Обработка капчи и блокировок

## 📝 Логирование

Все события записываются в логи:

- Найденные объявления
- Отправленные сообщения
- Ошибки скрэпинга
- Статус WhatsApp

## 🔄 Расширение

Для добавления новых сайтов:

1. Создайте новый сервис, наследующий `BaseScraperService`
2. Реализуйте интерфейс `ScraperInterface`
3. Добавьте в `ScrapingService.scrapers`

## ⚠️ Важные замечания

- Соблюдайте robots.txt сайтов
- Не превышайте разумные лимиты запросов
- Уважайте права пользователей на приватность
- Используйте прокси при больших объемах

## 🐛 Устранение неполадок

### WhatsApp не подключается

```bash
# Удалите данные сессии
rm -rf .wwebjs_auth/

# Перезапустите приложение
yarn start:dev
```

### Ошибки скрэпинга

- Проверьте изменения в структуре сайтов
- Обновите селекторы в скрэперах
- Используйте VPN при блокировках
